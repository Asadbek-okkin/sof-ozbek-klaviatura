# Sof Özbek klaviatura

Android klaviaturasi — 2026-yilgi yangi o'zbek lotin alifbosi uchun (Ö Ş Ç Ğ, tutuq ʼ).

- Gboard uslubidagi joylashuv, raqamlar qatori, smayliklar
- So'z takliflari va avtomatik tuzatish (120 000 so'zlik lug'at), o'rganadi
- Ovozli yozish, kirill / eski lotin matnni yangi alifboga o'girish
- Rus va ingliz klaviaturasi, bufer, tahrir paneli, 5 ta mavzu
- Yozilgan matn hech qayerga yuborilmaydi; internet faqat yangi versiyani tekshirish uchun

Yuklab olish: [Releases](../../releases/latest) → `SofOzbekKlaviatura.apk`.

Yig'ish: `bash build.sh` (JDK 17 + Android SDK 34, Gradle'siz). Lug'at: `vositalar/lugat_yasash.py`.
